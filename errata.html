Errata

Corrections to the printed edition. Page numbers are the page numbers printed in the book.

  1. Appendix D is missing an entry for uncial 065

    Where
    Appendix D, page 718 (between 063 and 070). Related: the manuscript apparatus note for John 12:1, page 297, note o.
    What the book has
    The note for John 12:1 correctly cites uncial 065 as a witness for the main text reading. Appendix D, which lists every manuscript cited in the edition, has no entry for 065.
    What it should say
    065 is a manuscript of the 6th century. It contains fragments of John, and so is listed as containing the Gospels.

    The missing line in Appendix D:

    GAWettsteinContentCentury
    063—eIX
    065—eVI
    070—eVI

    In Appendix D, “e” stands for the Gospels. The shaded row is the missing entry; the rows above and below it are printed in the book.

  2. Mark 4:8: Hodges-Farstad (HF) is missing from the reading ἕν … ἕν … ἕν

    Where
    Mark 4:8, page 100, note q.
    What the book has
    The note reads: ἐν … ἐν … ἐν ¦ ECM† txt ¦ WH εἰς … ἐν … ἐν ¦ ECM† NA SBL TR ἕν … ἕν … ἕν. HF is not named in the last reading, though it reads the same words as ECM†, NA, SBL and TR.
    What it should say
    The last reading should be ECM† HF NA SBL TR ἕν … ἕν … ἕν.

  3. Mark 4:20: Hodges-Farstad (HF) is missing from the reading ἕν … ἕν … ἕν

    Where
    Mark 4:20, page 101, note n.
    What the book has
    The note reads: ἐν … ἐν … ἐν ¦ ECM† txt ¦ WH ἐν … [ἐν] … [ἐν] ¦ ECM† NA SBL TR ἕν … ἕν … ἕν. HF is not named in the last reading, though it reads the same words as ECM†, NA, SBL and TR.
    What it should say
    The last reading should be ECM† HF NA SBL TR ἕν … ἕν … ἕν.

  4. Mark 12:31: the note for HF is missing

    Where
    Mark 12:31, page 136.
    What the book has
    No note covers the word αὕτη, though HF reads αὐτῇ there.
    What it should say
    The apparatus should have this entry, between notes r and s: 12:31 αυτη ¦ HF αὐτῇ.
