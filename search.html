Variant search

Choose an edition, a passage, a kind of difference, or a Greek word, and see every matching note in the Edition Apparatus with its page number. The strip shows where in the edition the matches fall. For the totals instead, see the stats.

Choose what to look for

    An edition not named in a note reads the same as the main text. Accents, punctuation, movable nu, final sigma, and spacing in compound words are not recorded in the apparatus. A note records only a place where at least one edition differs from the main text, so these figures describe the apparatus, not the editions as a whole. Readings appear exactly as the edition prints them. Most are printed without accents; where the edition prints a reading with accents, the accents are kept. Page numbers are the numbers printed in the book. The kind of difference is worked out automatically by comparing the printed words. A reading that does more than one thing (for example, omits one word and adds another) is listed under each kind, so the kinds overlap and should not be added together. “A different word” is used only when a word stands in the same place as the word it replaces. When one word is dropped in one place and another is put in somewhere else, the reading is listed as omitting words and adding words. “Krasis” is used only for the closed set of joined forms in which και and the next word are written as one, such as κακει for και εκει. Words are matched to their dictionary entries using the Strong’s numbers of the Robinson-Pierpont text, so “same word, different spelling or form” and “a different word” are only given when both words are recognized with certainty. Where the program could not be sure, the note is left with no label. The CSV download contains every matching note, not only the ones shown on the page, with one row for each reading, one row for each case where an edition prints the main-text reading in brackets, and one row where ECM prints a split guiding line. When a note is also one of the fifty variants, the last column of its rows lists the manuscripts cited for each reading, with the readings separated by ‖, with raised marks written as superscript characters (for example 399ᶜᵛⁱᵈ).
